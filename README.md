# Roaring Knight

The Roaring Knight fight from DELTARUNE Chapter 3, playable in the browser.

Everything here was extracted from the game's own files: sprites, sounds, music, text and the fight's code, which was converted to JavaScript so it runs in a web page. The Knight's attacks, the menus, the dialogue and the game over screen with FIGHT AGAIN work the same way they do in the game.

There is also a practice mode where you can pick any of the Knight's attacks and repeat it as many times as you want. In the settings you can put the ShadowMantle on Kris or take it off.

## Controls

You need a keyboard.

- Arrow keys: move
- Z or Enter: confirm
- X or Shift: cancel
- F4: fullscreen
- Hold Esc: back to the menu
